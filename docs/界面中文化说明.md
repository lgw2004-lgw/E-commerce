# 界面中文化说明

本地版本默认使用中文，翻译覆盖应用介绍、数据库说明、模型配置表单、知识库、工作流、图表标签、按钮、占位提示和操作反馈。DB-GPT、DeepSeek、MySQL 等固定名称，以及模型标识、数据库表名、字段名、SQL、路径、API 参数等技术标识保留原样。

## 修改位置

- `DB-GPT/web/locales/zh/`：中文语言包。
- `DB-GPT/web/components/`、`new-components/`、`pages/`：原来直接写在组件中的界面文案。
- `DB-GPT/web/lib/ui-translations.zh.json`：后端提供的内置功能、表单参数和工作流节点说明的中文对照。
- `DB-GPT/web/lib/ui-zh.ts`：仅处理已知的展示文案；接口参数、模型标识、SQL 和业务结果内容保持原值。
- `DB-GPT/packages/dbgpt-serve/src/dbgpt_serve/agent/db/gpts_app.py`：内置应用的中文介绍。

用户自己输入的内容、已有历史对话和大模型生成的回答不会自动改写。模型回答的语言由提问和模型提示词决定。

## 重新构建

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_web.ps1
```

输出目录为 `DB-GPT/web/out`。构建需要 Node.js 和前端依赖。构建成功后，执行以下命令备份旧版页面、发布并重启服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish_web.ps1
```

发布目录为 `DB-GPT/packages/dbgpt-app/src/dbgpt_app/static/web`。本地构建还调整了图标的按需引入，以及图表库 D3 依赖的打包方式，以适配当前 Node.js 环境。

原始前端源文件备份、替换前的静态页面和元数据库备份保存在 `work/chinese-ui-backup/`。中文修改后的版本仍通过根目录的 `start.cmd` 启动。
